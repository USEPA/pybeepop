Bee colony modeling

🐝 pybeepop+

Python interface for BeePop+, the EPA/USDA honey bee colony simulation model.

For more information about BeePop+ see Garber et al. 2022, Ecologies.
For more information about pybeepop+ see Minucci 2025, Journal of Open Research Software.

Note: All values in the input file are text strings. The "Type" column below indicates the internal type the string is converted to. Integer fields must be whole numbers. Values outside the listed Min/Max range are rejected with an error.
